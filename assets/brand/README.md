# SwarmLoom 品牌资产 / Brand assets

本目录的 SVG 和 PNG 全部由 `scripts/` 里的代码生成，不要手改。品牌常量（名称、双语标语、主色、12 色光标顺序、中性色、名牌规格）以 `palette.json` 为准，与 `contracts/brand.md` 一致。

Every SVG and PNG here is generated by the code in `scripts/`; do not edit them by hand. `palette.json` is the single source of the brand constants.

## 文件 / Files

| 文件 | 用途 |
|---|---|
| `logo.svg` / `logo-dark.svg` | 标志：光标穿过织机经纬线的方块，亮 / 暗背景各一版 |
| `logo-maskable.svg` | 满版底色、图形收进 80% 安全区，只用来导出 `icon-maskable-512.png` |
| `favicon.svg` | 加粗线条的小尺寸版本，浏览器暗色界面下自动提亮 |
| `wordmark.svg` / `wordmark-dark.svg` | 标志 + 字标横排组合，字形已转曲线，不依赖字体 |
| `icon-{16,32,48,128,192,512}.png` | 透明底应用图标；48 px 及以下用 favicon 版本 |
| `icon-maskable-512.png` | PWA maskable 图标（不透明） |
| `social-preview.png` | GitHub 社交预览图，1280×640 |
| `og-zh.png` / `og-en.png` | Open Graph 分享图，1200×630 |
| `hero-light.svg` / `hero-dark.svg` | README 头图：1280×420，8 s 循环，纯 CSS 动画，无脚本无外链；`prefers-reduced-motion` 时直接显示终帧 |
| `cards/<id>-{light,dark}.svg` | README 功能卡片，10 组：web、docs、pdf、html-svg、slides-sheets、code、images、3d、platforms、video |
| `palette.json` | 品牌常量 |
| `fonts/` | 字标与社交图用的 Bricolage Grotesque（SIL OFL 1.1，见 `fonts/OFL.txt`） |

README 里按配色切换头图：

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="assets/brand/hero-dark.svg">
  <img alt="SwarmLoom 群织：让一群光标，把它织出来。" src="assets/brand/hero-light.svg" width="1280">
</picture>
```

各端（site、studio、extension 等）在构建时复制需要的文件，不要在 git 里另存副本。

## 重新生成 / Regenerate

在仓库根目录执行（Node 22.12+，直接运行 TypeScript）：

```sh
node assets/brand/scripts/generate.ts           # 写出全部 SVG
node assets/brand/scripts/generate.ts --check   # 只校验已提交的 SVG 是否最新
SWARMLOOM_CHROME=$HOME/bin/chromium node assets/brand/scripts/rasterize.ts   # 用 Chromium 导出 PNG
node assets/brand/scripts/preview.ts hero dark  # 视觉检查用的帧截图，写到临时目录
pnpm --dir assets/brand run typecheck
pnpm --dir assets/brand test
```

PNG 导出依赖仓库已有的 `playwright`，Chromium 查找顺序：`SWARMLOOM_CHROME`、`~/bin/chromium`、Playwright 自带版本。社交图里的中文使用系统 CJK 字体（优先 Noto Sans CJK SC），换机器导出前先确认已安装。

生成过程是确定的：同一份 `palette.json` 每次得到逐字节相同的 SVG；动画只用固定种子的伪随机数，不读时钟。

## 设计要点 / Design notes

- 光标是原创的弯月形箭头：圆润尖端、无尾柄、1 px 白描边加柔和投影，不沿用任何系统或其他产品的光标造型。
- 标志里光标压在两根经线上、从珊瑚色纬线下穿过，光标本身就是梭子。
- 名牌为 6 px 圆角药丸、11 px / 600 系统字体、白字；亮度高的光标色（琥珀、青柠等）只在名牌底色上加深到白字对比度至少 3:1。
- 名牌用染料名命名（Indigo、茜红、铜绿、Weld、Tyrian、天青……），中英混排是有意为之。
