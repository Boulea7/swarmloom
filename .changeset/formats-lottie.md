Lottie animations open everywhere formats are detected: `.lottie` archives by their manifest and animation entries, Lottie JSON by its content (also under a `.json` name, which stays code for other JSON). The adapter loads on demand. Studio lists Lottie, gives the sample a gallery card and names pasted Lottie JSON so it opens as an animation.
