First release (0.1.0). A swarm of cursors rebuilds web pages, documents, images, code and 3D models in front of you, driven by one deterministic player: the same seed and clock give the same frames and the same sound events.

- `@swarmloom/core`: planner, built-in choreographies, isolated stage, cursor overlay, sound and the player API.
- `@swarmloom/snapshot-dom` and `@swarmloom/formats`: turn a live page or a file into a Blueprint; format adapters load lazily.
- `@swarmloom/element`: the `<swarm-loom>` Web Component.
- `@swarmloom/export` and the `swarmloom` CLI: frame-by-frame video export with an offline-rendered soundtrack.
- Browser extension for Chrome, Edge, Firefox and Safari, and the Studio web app.

Which formats and platforms are stable, in preview or planned is listed in the documentation.
