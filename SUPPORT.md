# 获取支持 / Support

## 中文

### 提问与讨论

使用 [GitHub Discussions](https://github.com/Boulea7/swarmloom/discussions) 询问安装、使用、适配器开发和设计问题，或讨论尚未形成明确任务的想法。提问前请先搜索已有讨论、Issue 和文档。

提问时请说明目标、已经尝试的方法、SwarmLoom 版本，以及必要的最小复现样例。不要上传凭据、私人文档或其他敏感数据。

### 报告问题或提出建议

通过 [GitHub Issue 表单](https://github.com/Boulea7/swarmloom/issues/new/choose) 选择合适类型：

- **缺陷报告 / Bug report**：可复现的错误行为；
- **功能建议 / Feature request**：明确的功能或交互建议；
- **新格式申请 / Format request**：申请支持新的输入格式；
- **平台问题 / Platform issue**：只出现在特定浏览器、操作系统或设备上的问题。

一个 Issue 只讨论一个问题。请提供环境、步骤、预期和实际结果；截图或录屏有助于说明视觉与播放问题。

安全问题不要公开讨论，请按 [安全政策](SECURITY.md) 使用 GitHub 私密漏洞报告。

## English

### Questions and discussions

Use [GitHub Discussions](https://github.com/Boulea7/swarmloom/discussions) for installation, usage, adapter development, and design questions, or to explore ideas that are not yet actionable tasks. Search existing discussions, issues, and documentation first.

State your goal, what you tried, your SwarmLoom version, and a minimal reproduction where relevant. Do not upload credentials, private documents, or other sensitive data.

### Reporting problems and requesting changes

Choose the appropriate [GitHub issue form](https://github.com/Boulea7/swarmloom/issues/new/choose):

- **Bug report / 缺陷报告**: reproducible incorrect behavior;
- **Feature request / 功能建议**: a specific feature or interaction proposal;
- **Format request / 新格式申请**: support for a new input format;
- **Platform issue / 平台问题**: a problem specific to a browser, operating system, or device.

Keep each issue focused on one problem. Include the environment, steps, expected and actual results; screenshots or recordings help with visual and playback problems.

Do not discuss security vulnerabilities publicly. Follow the [security policy](SECURITY.md) and use GitHub private vulnerability reporting.
