> 让一群光标，把它织出来。

SwarmLoom 是一段可视化重放：一群虚拟光标当着你的面，把网页、Markdown、Word、PDF、SVG、幻灯片、表格、代码、图片和 3D 模型一块一块搭出来，并且可以导出带声音的视频。它不是 AI agent 编排器，光标都是本地动画，内容不会离开你的设备。

## 状态

项目正在开发中，**暂无可安装的版本**。第一个公开版本会包含：

- 浏览器扩展：Chrome、Edge、Firefox（桌面与 Android）、Safari（macOS、iOS、iPadOS）
- Studio：可安装的网页应用，支持拖入文件、手机、平板、折叠屏和手表播放器
- CLI：逐帧确定性导出 MP4/WebM/GIF
- `<swarm-loom>` Web Component

## 致谢

灵感来自 Joel Califa 的 Swarm 网站和 Dhvanil Patel 的 Swarm Rebuild 扩展。SwarmLoom 是独立的 clean-room 重写，没有复用它们的代码、光标图形或配色。
