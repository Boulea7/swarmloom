# 支持的格式

::: info 当前状态
本页列出的格式都已有可用的读取器，可在 Studio 和 CLI 中打开；`swarmloom formats` 会输出当前列表。下文说明各格式会保留、简化或省略哪些内容。
:::

所有输入先变成格式无关的 **Blueprint**：它记录世界尺寸、背景、图层、阅读顺序和必要的插件。播放器只关心图层与编排，不需要理解原始文件。

文档类格式通常走“解析 → 安全 HTML → 固定宽度排版 → DOM 快照”。矢量、位图和 3D 使用各自的专用管线。大型解析器按需加载，不进入默认播放路径。

## 实时网页 DOM

**输入：** 扩展当前标签页、选中的元素，或 `SourceInput.element`。

快照读取元素几何、计算样式、文字、图片和开放的 Shadow Root。布局容器先建立，标题和正文随后输入，重复卡片可以表现为选中母版后拖出副本，共享边缘可生成参考线。

视频、WebGL canvas、跨源 iframe 等无法可靠拆解的区域使用截图或带标签的媒体占位。复杂脚本不会作为重建的一部分执行。

动画图片在重建中保持静止：动画 SVG（`<img>`，或带 SMIL 的内联 `<svg>`）去掉 SMIL 动画，CSS 动画停在第一帧；GIF、APNG、动画 WebP 和 AVIF 动图显示第一帧，嵌在 SVG 里（`<image>`、`<feImage>`）的也一样。图片里的动画按浏览器自己的时钟运行，视频无法逐帧重现。这适用于 `data:` URL，以及与页面同源的图片文件和 `blob:` URL，文字行内的小图标、视频封面和 CSS 背景图（包括遮罩和列表符号）也一样；CLI 渲染 go live 后的真实页面里，`<img>` 动图、内联 SVG 里的图片和元素的 CSS 背景图同样停在第一帧（伪元素上的除外）。跨源的图片文件仍按自己的时钟播放。

这是某一时刻的视觉快照，不是应用状态的克隆。表单输入、网络状态和事件逻辑不会被重放；“上线”返回的是原页面。

## HTML 与 HTML 动画

**扩展名：** `.html`、`.htm`、`.xhtml`

完整的 HTML 文档先清理，再在沙箱 iframe 中排版；HTML 片段清理后按当前主题排版。两者随后都复用 DOM 快照管线。HTML 输入不运行脚本，也没有开启脚本的选项。网络只允许加载 `https:` 图片和字体（不发送 Referer），其他请求一律禁止；Studio 设置里可以关闭这项加载。相对资源需要正确的 base URL；远程资源仍受 CORS、权限和站点访问控制影响。

CSS 动画在重建时冻结：有限动画取终态，无限动画停在半个周期处。上线后恢复原动画播放。宿主注册了关键帧时间轴插件（`anim:timeline`，来自 Lottie 适配器）时，最多六个带动画的元素还会在下方或上方的空白处多一条显示关键帧的时间轴，在页面织完后搭建。脚本驱动和事件驱动的动画不保证能还原。

## Markdown

**扩展名：** `.md`、`.markdown`、`.mdown`、`.mkd`

解析 CommonMark 与 GFM，保留标题、段落、列表、任务状态、表格、代码、链接、图片和脚注。标题在输入时长大，任务框先画勾，表格先画网格再填单元格，代码按预先计算的语法标记输入。

Markdown 没有唯一纸张尺寸或原始字体，因此使用 SwarmLoom 主题和固定排版宽度，不伪造原始分页。原始 HTML 默认按不受信输入处理。数学公式用 KaTeX 渲染，只在文档含公式时加载；Mermaid 代码块按代码显示。

## DOCX

**扩展名：** `.docx`

默认管线以保留样式为目标，将文档转换为安全、可测量的 HTML，再生成图层。常见段落、标题、列表、表格、图片、页眉页脚和显式分页参与重建。

HTML 排版不等于 Microsoft Word 的实时分页引擎。缺少可靠分页信息时按连续文档处理，不虚构页边界。需要严格保持原版式时，请先从 Word 导出 PDF。

设备上缺少的字体按一张共享回退表替换，DOC、PPTX、XLSX 和 OpenDocument 也用同一张表：有度量兼容开源字体的换成它（Calibri→Carlito、Cambria→Caladea、Arial→Liberation Sans、Times New Roman→Liberation Serif、宋体→Noto Serif SC、微软雅黑→Noto Sans SC，繁中、日文、韩文换成对应的 Noto 字体）。已安装原字体时优先用原字体，不随包分发字体文件，发生的替换写进加载提示。

样式渲染器处理不了某个文档时，内置的简化渲染器接手：保留标题、段落、列表、表格、超链接和分页符，省略图片、页眉页脚和脚注，并在加载提示中说明。

## DOC（Word 97–2003）

**扩展名：** `.doc`

旧版二进制 DOC 读取器用纯 JavaScript 打开复合文件（CFB），通过 piece table 解码正文。文档以文本模式打开：段落、标题、列表、表格、页眉页脚、脚注和尾注都用文档的正文字体显示，页面只在分节和显式分页符处断开。图片、字符格式（字体、字号、颜色、强调）、文本框、批注和浮动形状不显示，加载提示会说明。

加密、损坏或不受支持的结构会明确报错。以 `.doc` 后缀保存的 RTF 按内容识别，交给 RTF 读取器打开。

## PDF

**扩展名：** `.pdf`

PDF 使用独立管线：pdf.js 渲染页面位图，同时读取文本项、图片和绘制信息。最终文字区域从同一份页面位图中逐步揭示，避免重新排版导致字体、连字或 CJK 字形变化。

简单路径和图片可以先描画或扫入，文字沿自己的方向揭示。多栏阅读顺序优先使用文档结构，缺失时再推断。扫描件或已转曲文字没有文本层时，按区域或整页扫入，不假装逐字输入；OCR 不在首版承诺中。

页数、单页像素和绘制操作会受限。超限或加密文件会提示降级、截断或拒绝原因。

## SVG 与 SVG 动画

**扩展名：** `.svg`

矢量路径由钢笔光标放置锚点、牵引曲线并描边，随后出现填充、渐变和文字。`<use>` 实例可以表现为复制，分组与绘制顺序保留在 Blueprint 中。按宽度放大后高于 16:9 画面的图会整幅缩进画面，图标、徽章和方形图表织完时完整可见；明显竖长的图（如长流程图）保持满宽，跟随构建滚动。

带 SMIL 动画（`animate`、`animateTransform`、`animateMotion`、`set`、`mpath`）的 SVG 先按静态骨架重建，织完后动画版本淡入并从第 0 秒开始播放：构建期间跟随播放器时间，导出的视频逐帧确定；上线后按自己的时钟运行。同一 SVG 内的 CSS 动画和过渡共用这条时间轴：重放开始前停在 0 秒，之后随重放一起定位。只有 CSS 动画、没有 SMIL 的 SVG 暂不重放，显示第一帧。宿主注册了关键帧时间轴插件（`anim:timeline`）时，图下方先搭出一条带关键帧的时间轴，再播放动画。`href` 只允许指向文档内部的 `#片段`。脚本、外部资源和交互事件不会被执行。

## 幻灯片

**扩展名：** `.pptx`（`.odp` 由 OpenDocument 读取器打开）

每页幻灯片成为舞台上的一张页面，按演示文稿自身的幻灯片尺寸排布，16:9、4:3 和自定义尺寸都保持原比例。读取器综合幻灯片本身、版式、母版和主题：背景，预设与自定义形状及其填充、轮廓和阴影，带项目符号、编号和占位符继承的文字，裁剪后的图片，以及简单表格。

PPTX 是主要解析目标。旧版 `.ppt` 暂不支持：打开时会提示另存为 `.pptx` 或 PDF。图表、SmartArt、视频和其他嵌入对象显示为带标签的占位，原 PowerPoint 动画不会重放。

不读取 Keynote 文件，请先从 Keynote 导出 PPTX 或 PDF。

## 表格

**扩展名：** `.xlsx`、`.xlsm`、`.ods`、`.csv`、`.tsv`。旧版 `.xls` 暂不支持：打开时会提示另存为 `.xlsx` 或 CSV。

工作表按标签、列字母、行号、网格、表头和数据区域依次构建。关键单元格可以逐字输入，普通数据按空间分块盖章或填充；大型 used range 不会为每个单元格创建独立动画任务。

公式按文本和文件内缓存结果展示，**不会执行公式、宏、DDE、外部工作簿链接或网络查询**。缺少缓存值时显示表达式和提示，不伪造计算结果。图表只重建可解释的缓存系列，其余类型使用预览或数据表降级。

CSV/TSV 的编码和分隔符需要可解释的探测；无法确定时提供选择，不把开头为 `=` 的文本当公式执行。

## 源码与纯文本

**常见扩展名：** `.txt`、`.js`、`.jsx`、`.ts`、`.tsx`、`.json`、`.css`、`.scss`、`.py`、`.rb`、`.go`、`.rs`、`.java`、`.kt`、`.swift`、`.c`、`.cpp`、`.cs`、`.php`、`.sh`、`.sql`、`.yaml`、`.toml`、`.xml`、`.vue`、`.svelte`、`.lua`、`.dart`、`.scala` 等。

语法高亮在导入时计算一次，光标按 token 输入代码并保留空白与等宽排版。长文件按行或分块揭示，不在每一帧重新运行高亮器。

源码只作为文本处理，不会运行。纯文本没有可靠字体和样式信息，编码不确定时需要用户确认。

## 更多文档与开发者格式

| 格式 | 扩展名 | 重建方式 |
| --- | --- | --- |
| EPUB | `.epub` | 封面与章节转为安全页面，按书脊顺序重建 |
| OpenDocument | `.odt`、`.ods`、`.odp`、`.odg`；模板 `.ott`、`.ots`、`.otp`；Flat XML `.fodt`、`.fods`、`.fodp`、`.fodg` | 文本、表格、演示和绘图转为页面或幻灯片，公式不重算 |
| RTF | `.rtf` | 段落、字符样式、表格和图片转为分页 |
| OFD | `.ofd` | 文字、路径和图片按固定版式逐页重建，不验证签名 |
| Jupyter notebook | `.ipynb` | 依次重建 Markdown、代码和输出单元格，不连接真实内核；Markdown 单元格使用 Markdown 适配器的渲染器，公式保留 TeX 源码 |
| asciinema 终端录制 | `.cast` | 按录制节奏重放击键和输出，保留 ANSI 样式 |
| Patch / diff | `.diff`、`.patch` | 转为代码评审面板，删除线划除旧行并输入新增行 |
| XMind / FreeMind 思维导图 | `.xmind`、`.mm` | 从根节点向外绘制首个工作表的主题和连接线 |
| Lottie 动画 | `.lottie`、Lottie `.json`（按内容识别） | 先把一帧织成矢量图层，再拉出关键帧时间轴，随后按播放器时钟播放动画；不执行表达式 |

## 位图

**扩展名：** `.png`、`.apng`、`.jpg`、`.jpeg`、`.jfif`、`.gif`、`.webp`、`.avif`、`.bmp`

位图管线先提取边缘草图，再按空间分块上色，最后显示完整图片。光标沿边缘或绘制区域移动，而不是简单播放整张图片的淡入。

动图使用第一帧；接回原动画属于后续增强。超大图片可能降采样或分块处理，发生时会明确标记。

## 3D 模型

**扩展名：** `.glb`、`.gltf`、`.obj`、`.stl`、`.ply`

3D 适配器是自带 WebGL 舞台的插件。模型按连通面片组织，光标依次揭示顶点、特征边和三角面，随后出现材质、纹理与灯光，最后进行短距离相机环绕；完成后可拖动旋转，用滚轮或双指缩放。

GLB 是推荐的单文件分发形式。读取器只读这一个文件，不加载任何配套文件：引用外部 `.bin` 或纹理的 `.gltf` 会被拒绝，并提示导出为 GLB 或内嵌数据的 glTF；OBJ 的 `mtllib` 材质和贴图不会读取，改用调色板并在说明中注明。STL 等没有标准单位的格式需要单位或向上轴覆盖。

大模型使用确定的 LOD 和抽样预算；减少动态效果模式直接呈现静态完成态，不自动环绕。WebGL 不可用或模型超出预算时会明确报错或提示降级。

## 导出格式

CLI 的 `render` 命令可以输出以下格式（`swarmloom doctor` 会显示本机 ffmpeg 支持哪些）：

| 格式 | 用途 | 声音 |
| --- | --- | --- |
| MP4 | 通用分享，H.264、`yuv420p`、fast start | 支持同步音轨 |
| WebM | 浏览器与开放 Web 工作流，VP9 / Opus | 支持同步音轨 |
| GIF | 简短、兼容的旧式动画 | 不支持 |
| 动画 WebP | 更紧凑的网页动画 | 不支持 |
| PNG 序列 | 后续剪辑、合成与逐帧校验 | 单独提供 WAV |

Studio 的浏览器内导出运行与 CLI 相同的渲染页和虚拟时钟，输出 MP4（浏览器没有 H.264 编码器时输出 WebM）。它从 SVG 快照而不是截图绘制每一帧，少数样式可能不同，见 [Studio](./studio#导出与分享)。其他格式和作为基准的结果使用 CLI，并固定种子、视口、帧率、主题和依赖版本。
