<h1 align="center">SwarmLoom</h1>

<p align="center"><strong>看一群游標，把它織出來。</strong><br/>網頁、文件、程式碼、圖片和 3D 模型，都由一群游標在你眼前逐步建構，還能匯出含聲音的影片。<br/>這是在本機進行的視覺化重播，不是 AI 代理編排工具。</p>

## 運作原理

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="../../docs/assets/how-it-works-dark.svg" />
    <img alt="讀取網頁或檔案，依閱讀順序安排游標，再即時播放或匯出影片" src="../../docs/assets/how-it-works-light.svg" width="760" />
  </picture>
</p>

SwarmLoom 會將網頁或檔案拆成多個圖層，依閱讀順序交給游標處理。Studio 會即時播放建構過程；CLI 逐影格擷取畫面並加入聲音，因此匯出結果不受電腦速度影響。

## 快速開始

### 線上試用

開啟[線上 Studio](https://boulea7.github.io/swarmloom/studio/)，選擇範例，或拖入本機檔案、貼上文字、輸入網址。本機檔案只會留在瀏覽器中。輸入網址時，瀏覽器會直接向該網站發出請求，且對方必須允許跨來源讀取。

### 從原始碼建置

GitHub Releases、npm 套件與商店上架版本仍在規劃中，目前請從原始碼建置。需要 Node.js 22.12+；pnpm 版本固定於 `packageManager`。

```bash
git clone https://github.com/Boulea7/swarmloom.git
cd swarmloom
corepack enable
pnpm install
pnpm build
```

### CLI

在儲存庫根目錄執行以下指令，將檔案轉成影片：

```bash
node apps/cli/dist/cli.js render examples/svg/emblem.svg -o emblem.mp4
```

需要 Chrome 或 Chromium；匯出 MP4、WebM、GIF 和 WebP 還需要 FFmpeg 4+。執行 `node apps/cli/dist/cli.js doctor` 檢查環境。npm 套件發布後，即可直接使用 `npx swarmloom`（規劃中）。

### Web Component

npm 套件 `@swarmloom/element` 尚未發布（規劃中），但元件本身已可使用：

```html
<script type="module">
  import { define } from "@swarmloom/element";
  define();
</script>

<swarm-loom
  src="./demo.md"
  type="markdown"
  agents="24"
  seed="7"
  autoplay
  controls>
</swarm-loom>
```

所有屬性與事件請參閱[元件指南](https://boulea7.github.io/swarmloom/docs/en/element.html)。

## 依平台安裝

商店版本與已簽章的安裝套件尚未發布。以下均使用上一步 `pnpm build` 產生的開發版套件。

<details>
<summary>Chrome / Edge / Brave / Opera</summary>

- Chrome：開啟 `chrome://extensions`，啟用「開發人員模式」，選取「載入未封裝項目」，然後選擇 `apps/extension/dist/chrome/`。
- Edge：開啟 `edge://extensions`，選擇 `apps/extension/dist/edge/`。
- Brave / Opera：在各自的擴充功能頁面啟用開發人員模式，同樣選擇 `dist/chrome/`。
- 在一般網頁上，點選工具列圖示或按 Alt+Shift+W。瀏覽器內部頁面、網路商店與內建 PDF 檢視器不允許擴充功能執行。

</details>

<details>
<summary>Firefox 桌面版與 Android（簽章版規劃中）</summary>

桌面版：開啟 `about:debugging#/runtime/this-firefox`，選取「載入暫時附加元件」，選擇 `apps/extension/dist/firefox/manifest.json`；重新啟動 Firefox 後會將其移除。Android 使用同一套件；除錯需要 web-ext、ADB，以及一台已啟用除錯功能的裝置。若要長期安裝，需等待 AMO 簽章版本；在那之前，手機上請使用 Studio PWA。

</details>

<details>
<summary>Safari macOS / iOS / iPadOS / visionOS（實機測試與簽署規劃中）</summary>

在裝有 Xcode 的 Mac 上執行 `pnpm --filter @swarmloom/extension package:safari`，用 Xcode 開啟 `apps/extension/build/safari/`，選擇你的開發團隊並執行容器 App，再到系統設定中啟用擴充功能。安裝到裝置上需要加入 Apple Developer Program；這些系統的實機測試尚未完成。

</details>

<details>
<summary>PWA：桌面、Android、iOS / iPadOS</summary>

在 Chrome / Edge 中開啟 Studio，使用網址列或選單中的「安裝應用程式」。macOS Safari 請選「加入 Dock」；Android 請選「安裝應用程式」或「新增至主畫面」；iOS / iPadOS 請從 Safari 的分享選單選擇「加入主畫面」。Firefox 桌面版請直接在一般分頁中使用 Studio。

</details>

<details>
<summary>摺疊螢幕與手錶</summary>

摺疊裝置不需額外安裝：瀏覽器支援 Viewport Segments 時，Studio 會切換為左右並排或上下排列的雙窗格；不支援時則使用一般版面。手錶沒有擴充功能，也不保證提供完整 PWA。開啟 `?watch=1` 可使用預設靜音的小型播放器，`?round=1` 則適用圓形錶面。較大的場景請在其他裝置上匯出，再觀看成果。

</details>

## 常見問題

1. **游標背後有 AI 嗎？** 不是。游標是依固定種子驅動的本機動畫，不會呼叫任何模型，也不會執行文件或 HTML 內的腳本。
2. **本機檔案會上傳嗎？** 不會。檔案會在你的瀏覽器中處理。只有在你開啟網站網址時，瀏覽器才會連絡該網站；HTML 所參照的網路圖片與字型可在 Studio 設定中停用。詳見[隱私權說明](../../PRIVACY.md)。
3. **為什麼有些頁面無法原地重建？** 瀏覽器不允許擴充功能在內部頁面、網路商店或內建 PDF 檢視器中執行。請改將檔案拖入 Studio；需要登入的一般網頁則可使用擴充功能。
4. **相同設定會產生位元組完全相同的 MP4 嗎？** 在輸入、瀏覽器、字型、作業系統與設定都相同時，畫面與聲音會逐影格一致。不過，不同編碼器版本產生的 MP4 檔案本身仍可能有位元組差異。
5. **手機和手錶可以安裝擴充功能嗎？** 手機目前請使用 Studio PWA；Firefox Android 簽章版仍在規劃中。手錶只提供小型播放器，沒有擴充功能，也不支援背景播放。
