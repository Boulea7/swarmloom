# Credits and licences

## Inspiration

SwarmLoom's multi-cursor rebuilding concept was inspired by:

- **Joel Califa's Swarm website**, for the idea of many cursors collaborating to build an interface in view.
- **Dhvanil Patel's Swarm Rebuild extension**, for demonstrating that interaction in a browser extension.
- **HaloFlux**, for high-level inspiration behind the planned audio-reactive halo finale.

Thank you to those authors for bringing these interaction ideas to a wider audience. SwarmLoom's multi-format adapters, deterministic engine, plugin architecture, cross-platform shells, offline audio and video pipelines are independently designed and implemented.

## Clean-room statement

The Swarm and Swarm Rebuild projects did not provide an open-source licence for our implementation to reuse. SwarmLoom therefore follows a clean-room approach:

- No copying, translating or adapting their source code;
- No reuse of cursor art, palette, label styling, sounds or other assets;
- Implementation works from high-level behaviour descriptions, public platform capabilities and independent technical design;
- Third-party code and assets are used only with clear, compatible licences and the required notices.

SwarmLoom's vector cursor, Loom Indigo `#5B5BF7`, measurement Accent `#FF4F7B`, cursor palette, name tags and synthesised sound design are original.

“Inspired by” does not imply that those authors endorse, contribute to, or license SwarmLoom.

## Assets and examples

Repository examples should be generated by the project or use licence-cleared assets. New third-party samples need author, source, licence and required attribution records. Do not commit documents, fonts, images, audio or models of unknown origin.

Release artifacts must retain complete third-party licences and NOTICE files. If you find an omission, open a [GitHub Issue](https://github.com/Boulea7/swarmloom/issues/new/choose) with the package, version and relevant file path.
