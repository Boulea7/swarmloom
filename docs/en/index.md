features:
  - title: Rebuilt, not replayed
    details: Adapters turn input into a format-neutral Blueprint. Cursors draw layout, type text, trace paths and reveal images before the final content returns.
  - title: From pages to 3D
    details: Planned inputs include live DOM, HTML, Markdown, DOCX, DOC, PDF, SVG, PPTX, sheets, source code, bitmaps and popular 3D models.
  - title: On every platform
    details: Chromium, Firefox and Safari extensions are planned alongside a desktop and mobile Studio PWA, with file and video fallbacks where extensions cannot run.
  - title: Deterministic video
    details: A seeded engine and virtual clock drive every frame. The same event timeline produces sound for MP4, WebM, GIF, animated WebP and PNG sequences.
  - title: Embeddable and extensible
    details: The planned developer surface includes createPlayer, adapters, choreography plugins, the <swarm-loom> element and a CLI.
  - title: Local by default
    details: Parsing, snapshots, playback and exports run locally. No content uploads, advertising, analytics SDKs or telemetry.
