# 隐私

SwarmLoom 的设计目标是：文件解析、DOM 快照、动画播放和导出都在用户的浏览器或本机 CLI 中完成，不上传内容到 SwarmLoom 服务。

完整政策以仓库的 [PRIVACY.md](https://github.com/Boulea7/swarmloom/blob/main/PRIVACY.md) 为准。本页是使用时的简要说明。

## 本地处理

| 数据 | 规划处理方式 |
| --- | --- |
| 本地文件 | 在浏览器或本机 CLI 中读取和解析，不因播放而上传 |
| 当前页面 DOM | 用户激活扩展后在本机快照，不发送到 SwarmLoom 服务 |
| 设置 | 保存速度、主题、声音和语言等偏好，不建立用户画像 |
| 导出结果 | 在本地生成和保存，由用户决定删除或分享 |
| 音效 | 通过 Web Audio 或离线音频合成，不需要上传录音 |
| 使用统计 | 不包含广告、分析 SDK、使用统计或遥测 |

打开本地文件不需要内容相关的网络请求。首次加载应用、尚未缓存的适配器或用户明确选择的外部资源，仍可能产生普通资源请求。网页版 Studio 在首次访问后，还会在后台下载全部适配器和视频导出模块，供离线使用。HTML 内容引用的 `https:` 图片和字体默认会加载，不发送 Referer；可以在 Studio 设置中关闭。

## 扩展权限

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 用户点击图标、菜单或快捷键后，临时访问当前标签页 |
| `scripting` | 在用户激活的页面注入重建脚本，关闭后恢复原页面 |
| `contextMenus` | 提供重建此页、重建选区和在 Studio 中打开 |
| `storage` | 保存速度、光标、主题、声音和语言等设置 |
| 可选站点权限 | 用户选择打开远程 PDF、文档或图片时按需获取文件 |

安装扩展本身不应让它读取所有标签页。基本页面重建不要求授予全部站点的永久权限。可选权限可以在浏览器扩展管理中撤销。

浏览器自身的同步、备份和站点数据机制由各浏览器政策决定。SwarmLoom 不接收这些设置副本。

## 远程 URL 与外部资源

只有用户主动打开远程 URL 时，浏览器才向对应站点请求内容。该站点可能记录自己的访问日志，远程页面引用的字体、图片或模型资源也可能产生额外请求。

Studio 不提供默认服务器代理，不要求用户提交 Cookie，也不会把登录态转发给 SwarmLoom。跨源读取仍受 CORS 和浏览器权限约束。

访问 GitHub Pages 等托管的文档或 Studio 时，托管方会按自己的政策处理托管请求。这与把文件内容上传到 SwarmLoom 服务不是同一件事。

## 分享链接

小型文本可以编码到 URL hash 的 `#d=` 参数中。hash 通常不随 HTTP 请求发送到托管服务器，但它仍是链接的一部分：

- 接收者可以解码并阅读内容；
- 链接可能保存在浏览器历史、聊天记录或系统分享日志中；
- 浏览器或服务的链接预览行为由各自实现决定。

`#d=` 里只认播放相关设置（种子、速度、光标数、标签、收尾、跟随），其他字段一律忽略。远程资源和音量只按接收者自己的设置，任何链接都改不了。

分享前检查凭据、私人文字、未公开材料和第三方版权内容。不要分享含密钥的配置、源码或文档。

## 麦克风

麦克风只用于可选的光环律动。必须由用户明确启用并授予浏览器权限，拒绝授权不影响普通播放、合成声音和导出。

音频分析用于计算本地显示所需的强度与频段，不是登录或遥测功能。使用结束后可在浏览器站点权限中撤销麦克风访问。

## 保存与清除

可以通过扩展设置、浏览器站点数据管理或卸载扩展清除本地状态。PWA 的缓存和设置也可以通过站点数据控制清除。

已导出的视频、WAV、PNG 序列、Blueprint 和分享链接不会随清除站点数据自动消失，需要分别删除。不同浏览器安装的 PWA 可能拥有独立存储。

## 安全报告

普通隐私问题可通过 [GitHub Issue](https://github.com/Boulea7/swarmloom/issues/new/choose) 反馈。安全漏洞不要公开披露，请按照 [安全政策](https://github.com/Boulea7/swarmloom/blob/main/SECURITY.md) 使用私密报告渠道。
