## 快捷键

| 按键 | 作用 |
| --- | --- |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | 在支持的页面启动或关闭扩展重建 |
| <kbd>Space</kbd> | 暂停或继续 |
| <kbd>M</kbd> | 开关声音 |
| <kbd>T</kbd> | 开关自动巡航 |
| <kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> | 切换到 1×、2×、3× 速度 |
| <kbd>R</kbd> | 从头重播 |
| <kbd>L</kbd> | 上线：返回原页面或最终静态内容 |
| <kbd>Esc</kbd> | 关闭播放器 |

快捷键在播放器获得焦点且没有编辑文本时使用。浏览器或操作系统保留的快捷键优先。

触屏上轻触空白舞台可显隐工具栏。按钮目标至少 44 CSS px，并避让安全区和可用的折叠屏分段。

## 常用设置

| 设置 | 可选值 | 建议 |
| --- | --- | --- |
| 光标数量 `agents` | `auto` 或明确数量 | 默认 `auto`，按图层和视口在 8–64 之间调整；手机减少并发 |
| 速度 `speed` | 大于 0 的倍率 | 先用 1×，长文档用 2× 或 3× |
| 标签 `labels` | `names`、`agents`、`roles`、`none` | 演示协作语义用 `roles`，画面简洁用 `none` |
| 主题 `theme` | `auto`、`light`、`dark` | `auto` 跟随系统与内容 |
| 跟随 `follow` | `scroll`、`tour`、`none` | 自由阅读用 `scroll`，视频用 `tour`，固定画面用 `none` |
| 结尾 `finale` | `flock`、`halo`、`none` | 群聚、声音响应光环，或直接结束 |
| 减少动态 `reducedMotion` | `auto`、开、关 | 保持 `auto`，尊重系统偏好 |
| 开场 `intro` | 开、关 | 重复嵌入小组件时可关闭 |

JavaScript API 还支持自定义标签数组、调色板、语言、种子和时钟。

## 巡航与手动滚动

- `scroll`：用户控制滚动，光标群跟随当前工作区域。
- `tour`：舞台按构建进度自动滚动，适合无人值守播放和导出。
- `none`：不自动滚动，适合单屏海报、幻灯片和模型。

长页面只挂载视口附近的图层。手动快速滚动时，规划器会优先处理当前可见内容，而不是坚持从页面顶部逐层做完。

## 声音

音效由 Web Audio 合成，不需要下载录音文件。规划提供四种音效包：

| 音效包 | 特点 |
| --- | --- |
| `studio` | 默认；清晰的键盘、鼠标与玻璃质感音符 |
| `soft` | 更轻、更柔和 |
| `8bit` | 复古数字音色 |
| `silent-keys` | 保留界面与完成提示，键盘声静音 |

声音按光标横向位置设置声像。音符可对齐到八分音符网格，默认 BPM 为 112；速度与暂停由同一个引擎时钟驱动。

浏览器通常要求用户手势才能启动音频。看到“点按开启声音”时，点击工具栏或舞台即可。自动播放失败不是文件损坏。

光环结尾可以响应合成音轨。麦克风输入是可选项，只有明确授权后才启用；拒绝授权不会影响普通播放和导出。

## 减少动态效果

`reducedMotion: "auto"` 会读取系统的 `prefers-reduced-motion`。开启后，构建改用快速交叉淡化，不做群聚、环绕或大幅移动。

减少动态不等于关闭声音。可以分别设置，避免听觉和视觉偏好互相覆盖。

## 上线与重播

“上线”在不同模式下的含义：

- **覆盖模式**：同步滚动位置，淡出重建舞台，恢复真实、可交互的原页面。
- **内联模式**：隐藏光标和临时辅助线，保留最终静态内容。

`replay()` 清空揭示进度并重新开始，不重新请求输入文件。`destroy()` 则释放 DOM、音频、监听器和插件资源；离开后应调用它。

## 在浏览器中录制 <Badge type="warning" text="规划中" />

Studio 的“导出”在支持 Region Capture 与 MediaRecorder 的浏览器中实时录制 WebM，并混入 Web Audio 音轨：

1. 让内容进入希望录制的布局与主题。
2. 选择“导出”，按浏览器提示选择当前标签页和录制区域。
3. 开始播放，结束后停止并保存 WebM。

这是墙钟实时录制，可能受机器负载影响。浏览器不支持时不会假装生成等价文件，而会显示对应的 CLI 命令。

需要确定性结果时使用 [CLI](./cli)：虚拟时钟每次推进 `1000 / fps` 毫秒，逐帧捕获，并把同一声音事件日志离线渲染成 WAV 后合流。

## 分享 <Badge type="warning" text="规划中" />

小型 Markdown、SVG 和代码可以压缩到 URL hash 的 `#d=` 参数中。大型文件和远程 URL 使用文件或 `?src=` 入口。

**链接可能直接包含原文。** 分享前检查密钥、私人信息、未公开文档和版权内容。收到链接的人可以看到其中内容，远程站点也可能记录自己的访问日志。
