features:
  - title: 重建，而不是播放录屏
    details: 适配器把输入转换成格式无关的 Blueprint。光标绘制布局、输入文字、勾画路径、揭示图片，再恢复最终内容。
  - title: 从网页到 3D
    details: 规划支持实时 DOM、HTML、Markdown、DOCX、DOC、PDF、SVG、PPTX、表格、源码、位图和主流 3D 模型。
  - title: 在每个平台观看
    details: 规划提供 Chromium、Firefox、Safari 扩展，以及桌面和移动 Studio PWA。受限环境使用文件导入或导出的动画。
  - title: 确定性视频
    details: 固定种子与虚拟时钟逐帧驱动。声音来自同一条事件时间线，规划导出 MP4、WebM、GIF、动画 WebP 和 PNG 序列。
  - title: 可嵌入，也可扩展
    details: 规划提供 createPlayer、格式适配器、编排插件、<swarm-loom> Web Component 和命令行工具。
  - title: 默认本地处理
    details: 文件解析、快照、播放与导出在本地完成。不上传内容，不含广告、分析 SDK 或遥测。
