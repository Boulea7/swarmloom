# swarmloom (CLI)

The SwarmLoom command line. `swarmloom render <file|url> -o out.mp4` will drive a local Chrome or Chromium frame by frame on a virtual clock and mux the offline-rendered soundtrack with ffmpeg; `snapshot`, `serve` and `formats` cover page capture, local Studio and the format list. Only `--help` and `--version` work in this skeleton; every subcommand reports that it is not implemented yet.
