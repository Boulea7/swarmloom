SwarmLoom群织

书签版Bookmarklet

不装扩展，也能召唤光标群 No extension? Bring the swarm anyway.

把 SwarmLoom 存成书签。在任意网页上点一下，一群光标就会当着你的面把这一页重新织出来。适用于 Chrome Android、iPhone 和 iPad 上的 Safari，以及不能安装扩展的电脑。 Save SwarmLoom as a bookmark. Tap it on any page and a swarm of cursors rebuilds that page in front of you. Works in Chrome on Android, Safari on iPhone and iPad, and on computers where you can't install extensions.

  1. 显示书签栏：Windows 和 Linux 按 Ctrl Shift B，Mac 按 ⌘ Shift B。 Show the bookmarks bar: Ctrl Shift B on Windows and Linux, ⌘ Shift B on a Mac.
  2. 把下面的按钮拖到书签栏上。 Drag the button below onto the bookmarks bar.
  3. 打开任意网页，点一下书签栏里的 SwarmLoom。重建过程中再点一次会停下。 Open any page and click SwarmLoom on the bookmarks bar. Click it again to stop a rebuild.

常见问题Questions

有的网站会打开一个新标签页？Why do some sites open a new tab?

有些网站禁止加载外部脚本。这时书签会把当前页面的副本交给 SwarmLoom Studio，在新标签页里重建。如果浏览器拦截了新标签页，页面顶部会出现 “Open in SwarmLoom Studio” 按钮，点它即可。 Some sites block outside scripts. The bookmarklet then hands a copy of the page to SwarmLoom Studio, which rebuilds it in a new tab. If the browser blocks the tab, an “Open in SwarmLoom Studio” button appears at the top of the page; tap it.

页面内容会被上传吗？Is the page uploaded anywhere?

不会。书签只从 GitHub Pages 加载 SwarmLoom 自己的代码。交给 Studio 的副本直接在你的浏览器里传递，密码框里的内容不会进入副本。 No. The bookmarklet only loads SwarmLoom's own code from GitHub Pages. The copy for the Studio goes straight from tab to tab inside your browser, and password fields are left out.

哪些页面用不了？Where doesn't it work?

浏览器自带的页面（设置、扩展商店、新标签页）和 PDF 阅读器不运行书签。PDF 和文档可以直接拖进 Studio。 Built-in browser pages (settings, extension stores, the new tab page) and PDF viewers don't run bookmarklets. Drop PDFs and documents into the Studio instead.

电脑上能装扩展的话？Can I use the extension instead?

可以。Chrome、Edge、Firefox 和 Safari 上推荐用扩展：它不受网站的脚本限制，几乎所有网页都能直接重建，不用跳转到 Studio。 Yes. On Chrome, Edge, Firefox and Safari the extension is the better choice: site script restrictions don't apply to it, so almost every page rebuilds in place without a trip to the Studio.
