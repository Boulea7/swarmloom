# Examples

Samples for the supported formats live here, one folder per format: Markdown, HTML and web pages, DOCX, DOC, PDF, SVG, PPTX, XLSX/CSV, OpenDocument, EPUB, RTF, OFD, notebooks, mind maps, diffs, terminal recordings, Lottie animations, source code, images and 3D models. Studio uses these samples for its sample wall, and the browser tests play each one to the end.

## Sources and licenses

Most samples are written for this repository, by a script checked in next to them or by hand. They are MIT like the rest of the repository.

Some samples contain material from elsewhere:

- `doc/headers-footers-unicode.doc` is a real Word file copied unchanged from the test data of the [word-extractor](https://github.com/morungos/node-word-extractor) project. It is the test file `HeaderFooterUnicode.doc` of [Apache POI](https://github.com/apache/poi), which had it years before word-extractor, so it is under the Apache License 2.0, Copyright The Apache Software Foundation, and ships with POI's NOTICE. [`doc/SOURCES.md`](doc/SOURCES.md) lists its original paths and SHA-256 hash. The other DOC samples, `doc/report.doc` and `doc/table.doc`, are generated by `doc/generate.py`.
- `docx/report.docx` and `slides/pitch.pptx` are built on the MIT-licensed default templates of [python-docx](https://github.com/python-openxml/python-docx) and [python-pptx](https://github.com/scanny/python-pptx), Copyright (c) 2013 Steve Canny, and keep some template parts unchanged (Word styles, theme and font table; PowerPoint thumbnail and presentation properties). [`docx/SOURCES.md`](docx/SOURCES.md) and [`slides/SOURCES.md`](slides/SOURCES.md) list them.
- `sheet/sales.xlsx` holds the fixed theme part that the MIT-licensed [openpyxl](https://foss.heptapod.net/openpyxl/openpyxl) writes into every workbook, Copyright (c) 2010 openpyxl; see [`sheet/SOURCES.md`](sheet/SOURCES.md).
- `pdf/brochure.pdf` embeds subsets of the fonts Chromium printed it with: Liberation Sans and Liberation Serif 1.07.4, Copyright (c) 2007 Red Hat, Inc., under the Liberation Fonts licence (GPL v2 with an exception that keeps documents embedding the fonts out of the GPL), and Noto Sans CJK SC glyphs, © 2014-2021 Adobe, under the SIL Open Font License 1.1. [`pdf/SOURCES.md`](pdf/SOURCES.md) lists them.

Each of these `SOURCES.md` files holds the full text of every license and NOTICE that applies.

Generate new samples where you can. A third-party sample needs a license that allows redistribution, and a `SOURCES.md` in its folder that records the author, the source, the license and any required attribution, like `doc/SOURCES.md`. This includes a generator that starts from a library's built-in template (python-docx's `Document()`, python-pptx's `Presentation()`): the template ships inside the output. Fonts count too: a PDF printed by Chromium embeds subsets of the machine's fonts, so its `SOURCES.md` names each embedded font and its licence. Do not add files of unknown origin, and trace a copied file to the project that first published it: a test file in one project's repository may come from another project, under another license, or from a web page with its own terms (word-extractor's `test03.doc` is New Media Rights' licensing chart, CC BY-NC, so it cannot ship here). Studio builds, and so the CLI package, copy these notes (files named `SOURCES`, `LICENSE`, `LICENCE`, `NOTICE`, `COPYING` or `ATTRIBUTION`, with any extension) next to the samples they cover; they get no gallery tile.
