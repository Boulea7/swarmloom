# Examples

One sample per supported format lives here (Markdown, HTML, DOCX, DOC, PDF, SVG, PPTX, XLSX/CSV, source code, images and 3D models). Every sample is generated by this project, by a script checked in next to it or by hand, so its license is clear: the samples are MIT like the rest of the repository. Do not add files copied from elsewhere. Studio uses these samples for its sample wall, and the browser tests play each one to the end.
