# Lottie sample

`shuttle-loop.json` is an original 4-second loop drawn for SwarmLoom: a loom frame, five warp threads, a weft thread drawn on and off with a trim path, a shuttle whose fill fades in and out as it travels, and a caption. `shuttle-loop.lottie` is the same animation packed as a dotLottie (v1) archive.

Both files are generated by `generate.mjs` (no After Effects export, no third-party artwork). The output is deterministic, so running it again gives identical files:

```sh
node examples/lottie/generate.mjs
```
