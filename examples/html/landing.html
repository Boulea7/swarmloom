Many formats, one stage

Web pages, Markdown, Office files, PDF, code, images and 3D models all play on the same engine.

Repeatable builds

With the same input, settings, browser and fonts, a fixed seed and a virtual clock repeat each frame and sound.

Sound that follows the hands

Key clicks, snaps and soft notes are panned with each cursor and rendered offline into the video.

How it works

  1. Pick what to rebuild: the current tab, a file, or a link.
  2. The cursors plan the build from the finished content and get to work.
  3. Watch it live, then export a video or hand the page back to the reader.
SwarmLoom is a visual replay, not an AI agent orchestrator. MIT licensed
