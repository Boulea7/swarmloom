> Watch a swarm of cursors weave it into being.

SwarmLoom is a visual replay: a swarm of virtual cursors builds a web page, Markdown, Word, PDF, SVG, slides, spreadsheets, code, images or a 3D model piece by piece in front of you, and can export it as a video with sound. It is not an AI agent orchestrator. The cursors are local animation and your content never leaves your device.

## Status

Work in progress. **There is no installable release yet.** The first public release will include:

- Browser extension: Chrome, Edge, Firefox (one package for desktop and Android), Safari (macOS, iOS, iPadOS, visionOS)
- Studio: an installable web app with file drop for desktop, phone and tablet; foldable layouts and a small watch player are experimental extras
- CLI: deterministic frame-by-frame export to MP4/WebM/GIF
- `<swarm-loom>` web component

## Credits

Inspired by Joel Califa's Swarm site and Dhvanil Patel's Swarm Rebuild extension. SwarmLoom is an independent clean-room rewrite and reuses none of their code, cursor art or colours.
