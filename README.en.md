<h1 align="center">SwarmLoom</h1>

<p align="center"><strong>Watch a swarm of cursors weave it into being.</strong><br/>A swarm of cursors builds web pages, documents, code, images and 3D models in front of you, piece by piece, and exports the result as a video with sound.<br/>It is a local visual replay, not an AI agent orchestrator.</p>

## How it works

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="./docs/assets/how-it-works-dark.svg" />
    <img alt="Read a web page or file, plan the cursors in reading order, then play live or export a video" src="./docs/assets/how-it-works-light.svg" width="760" />
  </picture>
</p>

SwarmLoom splits a web page or file into layers and hands them to the cursors in reading order. Studio plays the build live. The CLI captures it one frame at a time and adds the sound, so the export does not depend on how fast your machine is.

## Quick start

### Try it online

Open [Studio online](https://boulea7.github.io/swarmloom/studio/) and pick an example, drop in a local file, paste text or enter a URL. Local files stay in your browser. For a URL, your browser asks that site directly, and the site has to allow cross-origin reads.

### Build from source

GitHub Releases, npm packages and store listings are planned. For now, build from source. You need Node.js 22.12+; the pnpm version is pinned in `packageManager`.

```bash
git clone https://github.com/Boulea7/swarmloom.git
cd swarmloom
corepack enable
pnpm install
pnpm build
```

### CLI

From the repository root, turn a file into a video:

```bash
node apps/cli/dist/cli.js render examples/svg/emblem.svg -o emblem.mp4
```

You need Chrome or Chromium; MP4, WebM, GIF and WebP also need FFmpeg 4+. Run `node apps/cli/dist/cli.js doctor` to check your setup. Once the npm package is out, `npx swarmloom` will work directly (planned).

### Web Component

The `@swarmloom/element` npm package is not published yet (planned). The element itself works:

```html
<script type="module">
  import { define } from "@swarmloom/element";
  define();
</script>

<swarm-loom
  src="./demo.md"
  type="markdown"
  agents="24"
  seed="7"
  autoplay
  controls>
</swarm-loom>
```

See the [component guide](https://boulea7.github.io/swarmloom/docs/en/element.html) for every attribute and event.

## Install by platform

Store listings and signed packages are not out yet. Everything below uses the development packages that `pnpm build` produced in the previous step.

<details>
<summary>Chrome / Edge / Brave / Opera</summary>

- Chrome: open `chrome://extensions`, turn on Developer mode, select Load unpacked and choose `apps/extension/dist/chrome/`.
- Edge: open `edge://extensions` and choose `apps/extension/dist/edge/`.
- Brave / Opera: turn on Developer mode on their extensions page and choose the same `dist/chrome/`.
- On a normal web page, select the toolbar icon or press Alt+Shift+W. Browser-internal pages, web stores and the built-in PDF viewer do not let extensions run.

</details>

<details>
<summary>Firefox desktop and Android (signed release planned)</summary>

Desktop: open `about:debugging#/runtime/this-firefox`, select Load Temporary Add-on and choose `apps/extension/dist/firefox/manifest.json`; Firefox removes it on restart. Android uses the same package; debugging needs web-ext, ADB and a device with debugging turned on. A lasting install needs the AMO-signed release; until then, use Studio as a PWA on phones.

</details>

<details>
<summary>Safari macOS / iOS / iPadOS / visionOS (device testing and signing planned)</summary>

On a Mac with Xcode, run `pnpm --filter @swarmloom/extension package:safari`, open `apps/extension/build/safari/` in Xcode, choose your team and run the container app, then turn the extension on in system settings. Installing on a device needs the Apple Developer Program; testing on real devices for these systems is not done yet.

</details>

<details>
<summary>PWA: desktop, Android, iOS / iPadOS</summary>

In Chrome / Edge, open Studio and use Install app in the address bar or menu. On macOS Safari use Add to Dock; on Android use Install app or Add to Home screen; on iOS / iPadOS choose Add to Home Screen from Safari's Share menu. On Firefox desktop, use Studio in a normal tab.

</details>

<details>
<summary>Foldables and watches</summary>

Foldables need nothing extra: where the browser supports Viewport Segments, Studio splits into two side-by-side or stacked panes; elsewhere it uses the normal layout. Watches get no extension and no promise of a full PWA. Open `?watch=1` for a small player that starts muted, or `?round=1` for round faces. Export bigger scenes on another device and watch the result.

</details>

## FAQ

1. **Is there AI behind the cursors?** No. The cursors are local animation driven by a fixed seed. Nothing calls a model, and scripts inside documents or HTML never run.
2. **Are local files uploaded?** No. Files are processed in your browser. Your browser contacts a site only when you open its URL; images and fonts that HTML links to can be turned off in Studio settings. See [Privacy](./PRIVACY.md).
3. **Why can some pages not be rebuilt in place?** Browsers do not let extensions run on internal pages, web stores or the built-in PDF viewer. Drop the file into Studio instead; for a normal page that needs you to sign in, use the extension.
4. **Do the same settings give a byte-identical MP4?** Frames and sound match frame for frame (same input, browser, fonts, OS and settings). The MP4 file itself can still differ in bytes between encoder versions.
5. **Can phones and watches install the extension?** On phones, use Studio as a PWA for now; a signed Firefox Android release is planned. Watches only get the small player, with no extension and no background playback.

## Roadmap

- **Now**: Studio online, web pages plus 20 file formats, frame-by-frame CLI export, and Chrome / Edge / Firefox / Safari extensions built from source.
- **Next**: the first GitHub Release and npm packages, store listings and signed extensions, video export inside Studio, and testing on phones and Safari devices.
- **Later**: more formats and platforms, with no dates promised. Share ideas in [Ideas](https://github.com/Boulea7/swarmloom/discussions/categories/ideas).
