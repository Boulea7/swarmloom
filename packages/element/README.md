# @swarmloom/element

A `<swarm-loom>` custom element that plays a SwarmLoom build of a file or URL inside any page, for site intros and documentation demos. Call `define()` once to register the tag, then use attributes such as `src`, `type`, `agents`, `speed`, `autoplay`, `loop` and `controls`, or call `el.load(input)` from script.
