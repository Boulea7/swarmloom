# @swarmloom/adapter-three

The 3D model adapter for SwarmLoom. Pipeline: glTF/GLB/OBJ/STL/PLY built vertex by vertex on a WebGL stage. The package exports a stub `Adapter` with its id, extensions and MIME types; `load()` throws until the implementation lands. Load it through `@swarmloom/formats` so it is only fetched when needed.
